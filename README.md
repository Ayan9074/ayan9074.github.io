# Ayan Shariff — personal website

Basketball-themed static portfolio for https://ayan9074.github.io.

## Publish

1. Create a public GitHub repository named `ayan9074.github.io` under `Ayan9074`.
2. Upload the contents of this folder to the repository root, including `index.html`, `styles.css`, `app.js`, and `assets/`.
3. In Settings → Pages, choose **Deploy from a branch**, **main**, **/ (root)**, and Save.

The website is public once GitHub Pages publishes it. No build tools or ChatGPT hosting are required.

## Edit

Edit `index.html` for content, `styles.css` for appearance, and `app.js` for the interactive basketball court. The court and basketball are scalable SVG elements in `index.html`.
